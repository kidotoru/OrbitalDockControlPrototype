# Orbital Dock Control

惑星軌道上の宇宙ステーションで、やってくる宇宙機をどのドッキングポートに入れ、いつ出発させるかを管制するゲームのプロトタイプです。three.js + Vite + TypeScript。

## 遊び方

ステーションはリソース在庫とクレジットを持つ。リソースを安く仕入れて高く売り、クレジットを増やす。

- **サプライヤー**（供給）はリソースを運んでくる。1u あたり $0.50〜$0.70 で買い取る
- **コンシューマー**（補給）はリソースを買いに来る。1u あたり $1.00（評判0）〜$2.00（評判100）で売る。単価は取引開始時の評判で決まる
- 来る船はサプライヤー25%、コンシューマー75%。船のサイズ（S/M/L）で取引量が変わる。コンシューマーの取引量は同じサイズのサプライヤーの25%。待機中の船を選び、サイズが合う空きポートを指定する
- 取引はドッキング中に少しずつ進む。在庫・クレジット・貯蔵庫の空きが尽きると打ち切られ、評判が下がる
- 待たせすぎると離脱（評判↓）、衝突すると修理費（クレジット↓）
- ステーション自身も毎秒 0.1u のリソースを消費する。在庫が 0 になるとゲームオーバー
- 評判が高いほど船が多く来る
- 視点：ドラッグで回転、ホイール／ピンチでズーム

数値は `src/config.ts` にまとめてある。

## 開発

```bash
npm install
npm run dev      # 開発サーバー
npm run build    # dist/ に出力
```

`main` へのプッシュで GitHub Actions が GitHub Pages にデプロイします。

## 構成

| ファイル | 内容 |
| --- | --- |
| `src/world.ts` | レンダラー、カメラ、惑星（手続き生成テクスチャ）、星空 |
| `src/station.ts` | ステーションのモデルとドッキングポート定義 |
| `src/ship.ts` | 宇宙機の種類・モデル・経路追従 |
| `src/config.ts` | バランス調整用の数値（価格、積載量、運用費、評判など） |
| `src/game.ts` | ゲーム進行（出現、割り当て、取引、出発、接近警報、衝突、評判、ゲームオーバー） |
| `src/ui.ts` | HUD（交通リスト、ポート一覧、操作パネル、ログ） |

ブラウザのコンソールから `game` で内部状態にアクセスできます。
